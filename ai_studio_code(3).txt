คุณคือผู้เชี่ยวชาญด้าน Full-stack Web Development ช่วยสร้างเว็บแอพพลิเคชัน "YouTube WatchParty & 9-Seat Voice Stage" (ห้องดู YouTube พร้อมกันกับเพื่อนแบบเรียลไทม์ พร้อมเวทีไมค์ 9 ที่นั่ง ระบบแชทสด และระบบโปรไฟล์ภาพ)

### 🛠️ Tech Stack & Architecture:
1. Frontend: React 18, TypeScript, Tailwind CSS, Lucide React (ไอคอน), YouTube IFrame Player API
2. Backend: Express + WebSocket (ws) + Vite integration บนพอร์ต 3000 (Full-Stack architecture)
3. Voice Chat: WebRTC Mesh Audio & Web Audio API (Analysers สำหรับตรวจจับระดับเสียงพูดจริงแบบเรียลไทม์)
4. UI/UX: โทนสี Dark Theme ทันสมัย (#0f0f13, #151722, Slate 800) สะอาดตา responsive รองรับทั้ง Mobile และ Desktop

---

### 🌟 ฟีเจอร์และข้อกำหนดทั้งหมด (Detailed Requirements):

#### 1. 🎬 ระบบเล่น YouTube ซิงค์ตรงกันทุกคน (Synchronized Video Player)
- ใช้ YouTube IFrame Player API ฝังวิดีโอบนหน้าเว็บ
- เมื่อมีใครคนใดคนหนึ่งกด Play, Pause, หรือ เลื่อนแถบเวลา (Seek) ระบบจะส่ง WebSocket Event ให้ทุกคนในห้องซิงค์เวลาตรงกันทันที
- มีระบบ Drift Correction อัตโนมัติ: หากเวลาของผู้เล่นคลาดเคลื่อนเกิน 1.5 - 2 วินาที จะดึงเวลาให้ตรงกับห้องอัตโนมัติ
- มีระบบแสดงแจ้งเตือนสถานะการซิงค์แบบนุ่มนวล (Sync Notification Toast)

#### 2. 🎙️ เวทีไมค์ 9 ที่นั่ง (9-Seat Voice Stage)
- มีแถบเวทีไมค์แบ่งเป็น 9 ช่องที่นั่ง (#1 ถึง #9) วางเรียงอย่างสวยงาม
- การขึ้นนั่ง: ผู้ใช้ทุกคนสามารถคลิกที่นั่งว่างเพื่อขึ้นไปนั่งบนไมค์ได้
- รูปโปรไฟล์บนที่นั่ง: เมื่อมีคนนั่ง ต้องแสดงรูปโปรไฟล์จริง (รูปภาพที่อัพโหลดจากเครื่อง หรือรูปโปรไฟล์สำเร็จรูป) แทนรูปไอคอนอิโมจิ พร้อมชื่อและสีประจำตัว
- ระบบไมค์และการพูด:
  - มีปุ่มเปิด/ปิดไมค์สำหรับคนที่นั่งอยู่
  - มีระบบตรวจจับเสียงพูดจริงผ่านไมโครโฟน (AudioContext Volume Analyser)
  - เมื่อคนพูด จะมีวงแหวนสีเขียวเรืองแสง (Voice Ripple) กระพริบตามจังหวะเสียงพูด
  - มีไอคอนแสดงสถานะไมค์ (เปิดไมค์สีเขียว / ปิดไมค์สีแดง)
- การลงจากที่นั่ง: คนที่นั่งสามารถกดปุ่ม "ลงจากที่นั่ง" หรือย้ายไปนั่งช่องอื่นได้

#### 3. 🖼️ ระบบโปรไฟล์และอัพโหลดรูปภาพ (User Profile System)
- รองรับการตั้งชื่อ และเลือกสีประจำตัว
- การอัพโหลดรูปภาพ: สามารถเลือกไฟล์รูปภาพจากเครื่อง (PNG, JPG, WebP) และมีระบบย่อ/บีบอัดรูปภาพด้วย HTML5 Canvas อัตโนมัติให้อยู่ในขนาดกะทัดรัด (เช่น 160x160 Data URI) เพื่อให้ส่งผ่าน WebSocket ได้ลื่นไหล
- รูปโปรไฟล์สำเร็จรูป: มีชุดรูปโปรไฟล์เวกเตอร์ SVG สำเร็จรูป (เช่น สไตล์ Cyber, Anime, Gamer, DJ) ให้เลือกได้ทันทีสำหรับคนที่ไม่มีรูปภาพในเครื่อง
- รองรับการแก้ไขโปรไฟล์ได้ตลอดเวลา ทั้งจาก Navbar, หน้าเวทีที่นั่ง และหน้าช่องแชท

#### 4. 💬 ระบบแชทสดเรียลไทม์ (Live Chat Panel)
- ไม่ต้องแสดงตัวเลขจำนวนข้อความแชท: ที่หัวข้อแท็บ "แชทสด" ให้แสดงชื่อแท็บเรียบหรู โดยไม่ต้องมีป้ายตัวเลขนับจำนวนข้อความ
- แสดงรูปโปรไฟล์ที่หน้าช่องแชท: วางรูปโปรไฟล์กลมของผู้ใช้งานไว้ที่หน้ากล่องพิมพ์ข้อความแชทโดยตรง (คลิกเพื่อแก้ไขรูปโปรไฟล์ได้) เพื่อให้ผู้ใช้รู้ว่ากำลังพิมพ์ในฐานะใคร
- รูปโปรไฟล์ในกล่องข้อความ: ทุกข้อความแชทที่แสดงในห้อง ต้องแสดง รูปโปรไฟล์ของผู้ส่ง อย่างชัดเจน พร้อมชื่อผู้ส่งและสีประจำตัว เพื่อให้ทุกคนรู้ว่าใครพิมพ์ข้อความอะไร
- Timestamp ข้ามเวลาอัตโนมัติ: เมื่อมีคนพิมพ์เวลา เช่น "01:23" หรือ "2:45" ในแชท จะกลายเป็นลิงก์ที่ทุกคนสามารถกดเพื่อกระโดดข้ามวิดีโอไปยังวินาทีนั้นได้ทันที
- มีแถบปุ่มลัดสำหรับกดส่งอิโมจิด่วน (❤️, 🔥, 👏, 😂, 🎵, 🍿 ฯลฯ)

#### 5. 📋 ระบบค้นหาและจัดการ Playlist (Search & Playlist)
- มี Modal ค้นหาวิดีโอ YouTube ได้โดยตรง หรือวาง URL/Video ID ของ YouTube
- สามารถกด "เล่นทันที" หรือ "เพิ่มเข้า Playlist" ได้
- มีแท็บแสดง Playlist พร้อมภาพปก (Thumbnail), ชื่อคลิป, ช่อง, และความยาว
- มีตัวเลือกเล่นวนซ้ำ (Loop: ทั้งหมด / เพลงเดียว / ปิด)
- สามารถลบเพลง หรือล้าง Playlist ได้

#### 6. 🌐 ระบบห้องและแชร์ลิงก์ (Room & Collaboration)
- สร้าง Room ID ได้ง่าย หรือแชร์ผ่าน URL Hash (เช่น /#room=squad-chill)
- เมื่อเพื่อนเปิดลิงก์ จะเข้ามาร่วมห้องเดียวกันและซิงค์ทันทีโดยไม่ต้องลงทะเบียน
